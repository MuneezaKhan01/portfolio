Project Case Study

Skill Gap Analyzer

Problem

Job seekers may find it difficult to understand which technical skills are required for a specific role and how their existing skills compare.

My Role

Implementation

Used Python and the Adzuna API to collect job information. Structured the data and explored embedding-based approaches for matching skills.

Handling job description data, extracting relevant skills and exploring different approaches to semantic matching.

Outcome

Developed a practical understanding of working with external APIs, data processing and AI-assisted skill matching.
