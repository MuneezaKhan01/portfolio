# Muneeza Khan – Personal Portfolio

## About the Project
This is my personal portfolio website, developed to showcase my education, technical skills, projects, certifications, and professional profile.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Portfolio Features
- About Me section
- Education and skills
- Projects showcase
- Certifications and achievements
- Downloadable CV
- Contact information and social links
- Responsive website design

## Projects
The portfolio includes my academic and personal projects. Each project highlights my technical skills and learning experience.

## How to Run Locally
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
